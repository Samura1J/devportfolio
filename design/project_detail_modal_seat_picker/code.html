01

The Challenge

Managing complex multi-item selection across a large grid in React often triggers unnecessary full-matrix re-renders. Every click must immediately update both seat visual state and overall shopping cart tallies without UI stutter.

02

Architecture Solution

Modeled seat availability using an indexed coordinate hash map. Individual seat cells react only to their specific state changes, while an immutable selected set drives the price accumulator at the root tier.

03

Full Stack Evolution

Demonstrated core frontend transaction management that naturally extends to backend WebSocket seat concurrency locks, database transaction rollbacks, and checkout reservation expiration timers.

// State reducer ensuring idempotent seat toggle with tier valuation
export function toggleSeatSelection(currentSelection, seatId, seatTier) {
  const nextSelection = new Map(currentSelection);
  if (nextSelection.has(seatId)) {
    nextSelection.delete(seatId);
  } else {
    nextSelection.set(seatId, { ...seatTier, lockedAt: Date.now() });
  }
  const totalValuation = Array.from(nextSelection.values())
    .reduce((sum, item) => sum + item.priceUsd, 0);

  return { selectedSeats: nextSelection, totalPrice: totalValuation };
}
